# Code of conduct

SkillBOM follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people, and remember that many contributors are new to supply-chain security or to open source.

Report unacceptable behaviour privately to the maintainers through [GitHub private vulnerability reporting](https://github.com/grcmana/skillbom/security/advisories/new), marking it as a conduct report. Reports are handled confidentially.
